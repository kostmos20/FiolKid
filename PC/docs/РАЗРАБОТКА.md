# FiolKid для разработчика

Здесь — как программа устроена внутри, как её собрать и выпустить новую версию. Людям, которые
просто пользуются FiolKid, это не нужно: им хватит [README](../README.md).

Решения и их причины подробно описаны в [PLAN.md](PLAN.md).

## Как это устроено

```
                       ┌──────────────── FiolKid ────────────────┐
  YouTube, Discord ──► │ zapret (winws + драйвер WinDivert)       │ ──► напрямую, DPI не узнаёт
  Telegram ─────────►  │ tg-ws-proxy (127.0.0.1:1443)             │ ──► серверы Telegram
  ChatGPT, Instagram ► │ свой DNS → маршруты → туннель «FiolKid»  │ ──► VPN-сервер ──► сайт
  остальное ────────►  │                                          │ ──► напрямую
                       └──────────────────────────────────────────┘
```

- **zapret** (winws от Flowseal) работает только для доменов YouTube и Discord и меняет пакеты так,
  что оборудование провайдера (DPI) не узнаёт, куда идёт соединение. Способ обхода («альт») подбирается
  замером скорости.
- **tg-ws-proxy** — локальный MTProto-прокси: Telegram подключается к нему, а он ходит к серверам
  Telegram через WebSocket.
- **VPN** поднимается без своих маршрутов: AmneziaWG (`Table = off`) или sing-box (без auto_route).
  Что пустить в туннель, решает программа. Пока VPN включён, DNS Windows указывает на программу
  (127.0.0.1): вопросы о сайтах из списков она задаёт DNS Cloudflare через туннель и до ответа браузеру
  добавляет полученные адреса в маршруты VPN. Остальные вопросы уходят прежнему DNS.
  Прежние настройки DNS программа возвращает при выключении, а если она упала — сторожевой процесс.
- **Watchdog** проверяет сервисы настоящими запросами и переключает способы обхода.
- **Обновления** — раздел Releases этого репозитория. Описание выпуска подписано ключом автора
  (ECDSA P-256, открытый ключ встроен в программу), архив сверяется по размеру и SHA-256. Новая версия
  заменяет только изменившиеся файлы, не трогает `*-user.txt`, делает резервную копию и откатывается при сбое.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и PowerShell.

```powershell
# 1. Скачать zapret, tg-ws-proxy, AmneziaWG и sing-box с официальных релизов (со сверкой SHA-256)
powershell -ExecutionPolicy Bypass -File tools\fetch-deps.ps1

# 2. Тесты
dotnet test tests\ZapretPro.Core.Tests

# 3. Собрать dist\ и FiolKid.zip
powershell -ExecutionPolicy Bypass -File build.ps1
```

## Выпуск новой версии

Только для автора: нужен ключ подписи и вход в GitHub CLI.

```powershell
# один раз на компьютере автора: создать ключ подписи (хранится зашифрованным вне репозитория)
dotnet run --project src\ZapretPro.ReleaseTool -- keygen

# поднять <Version> в src\ZapretPro.App\ZapretPro.App.csproj, сохранить в git и отправить, затем:
powershell -ExecutionPolicy Bypass -File tools\publish-release.ps1 -Notes "Что нового"

# проверить выпуск так же, как это сделает программа у людей
dotnet run --project src\ZapretPro.ReleaseTool -- check
```

Выпуск собирается в папку `release\` — `dist\` и `FiolKid.zip` в корне при этом не меняются.

## Структура

| Папка | Что там |
|---|---|
| `src/ZapretPro.App` | окно, трей, вкладки (WPF) |
| `src/ZapretPro.Core` | вся логика: zapret, Telegram, VPN, свой DNS, проверки, обновления |
| `src/ZapretPro.KeyTool` | `ПроверитьКлюч.exe` — показывает, какой протокол в ключе |
| `src/ZapretPro.ReleaseTool` | ключ подписи выпусков и подпись (только для автора) |
| `tests/ZapretPro.Core.Tests` | тесты (xUnit) |
| `data` | способы обхода zapret и списки сайтов для VPN |
| `tools` | скачивание компонентов, обновление списков, значок, выпуск |
| `docs` | этот файл, план проекта и инструкция для архива |
