# План: приложение FiolKid (рабочее название было «Одна кнопка»; zapret + VPN)

Oct 20, 2026 · @Алексей

## Цель и требования

Нужно Windows-приложение, в котором главное действие — одна кнопка: бабушка нажимает её, и работают YouTube, Discord, Telegram и нейросети, а все российские сервисы продолжают работать как обычно, без всяких «включи-выключи».

«Одна кнопка» — не буквально. Кроме неё нужен простой интерфейс, чтобы вставить или поменять ключ VPN и увидеть, подключился ли VPN, а также посмотреть, что с обновлениями zapret и прокси Telegram (см. «Интерфейс» и «Обновления»).

Жёсткие требования:

- Главный экран — большая кнопка и индикаторы. Всё «умное» спрятано, но ключ, состояние VPN и обновления доступны в пару нажатий.
- Раздельная маршрутизация: через VPN идут только домены и IP из списков, остальное напрямую.
- Автоматическая проверка, что сервисы открываются, и автопереключение стратегий zapret, если что-то отвалилось.
- Автозапуск при включении компьютера с последней рабочей стратегией.
- Ключ `vpn://` вставляется через кнопку «Вставить ключ» и легко меняется, если знакомый выдаст новый.
- Никаких лишних файлов: логи только об ошибках, с ограничением размера.
- zapret (стратегии и списки) и прокси Telegram обновляются автоматически из официальных релизов Flowseal, с проверкой и откатом, если после обновления стало хуже.

| Сервис | Через что | Нужен сервер |
|---|---|---|
| YouTube | zapret (обход DPI), локально | Нет |
| Discord | zapret (обход DPI), локально | Нет |
| Telegram | tg-ws-proxy от Flowseal (локальный прокси), локально | Нет |
| Нейросети (ChatGPT, Claude, Gemini) | VPN по ключу `vpn://` | Да, сервер знакомого |
| Другие заблокированные в России сайты (Instagram, X и т. д.) | VPN по ключу: список itdoginfo/allow-domains (Russia inside, обновляется еженедельно, программа скачивает раз в сутки) + подсети Meta и X; домены YouTube/Discord/Telegram из списка исключаются | Да, сервер знакомого |
| Всё остальное (банки, Госуслуги, Яндекс и т. д.) | Напрямую, без изменений | Нет |

## Официальные источники

- zapret (winws.exe + WinDivert): https://github.com/bol-van/zapret — только официальные релизы.
- Стратегии и хостлисты: https://github.com/flowseal/zapret-discord-youtube
- Прокси для Telegram: https://github.com/Flowseal/tg-ws-proxy

Брать только из этих репозиториев, фиксировать версию и контрольные суммы. Перепаковки с похожими названиями не использовать.

## Архитектура

Приложение само решает, куда отправить каждый запрос. Если zapret перебрал все стратегии и не пробил YouTube или Discord, они временно уходят через VPN (запасной режим).

Маршрутизация трафика — 3 пути и запасной режим:

1. YouTube, Discord → zapret (локально).
2. Telegram → tg-ws-proxy (локально).
3. Нейросети → VPN.
4. Остальное → напрямую.
5. Запасной режим: YouTube/Discord/Telegram → VPN.

### Компоненты Windows-приложения

Рекомендуемый стек: C# на .NET 8 (WPF), сборка в один exe с self-contained публикацией и установщиком (Inno Setup). Так бабушке не нужно ставить .NET отдельно, а права администратора удобно прописать в манифесте.

| Модуль | Что делает |
|---|---|
| KeyParser | Распаковывает ключ `vpn://`, определяет протокол, достаёт параметры подключения. Ключ хранится зашифрованным через Windows DPAPI, не в открытом виде. |
| ZapretManager | Запускает и останавливает winws.exe с нужной стратегией и хостлистом, хранит список стратегий. Отдельно запускает tg-ws-proxy для Telegram. |
| VpnManager | Поднимает и опускает VPN-туннель через выбранное ядро (см. раздел про ключ). |
| Router | Отвечает за раздельную маршрутизацию: какие домены и IP идут в VPN, какие напрямую. |
| HealthChecker | Каждые 2–3 минуты проверяет доступность YouTube, Discord, Telegram, нейросетей. |
| Watchdog | Если проверка провалилась, перезапускает компонент или переключает стратегию. Перезапускает упавшие процессы. |
| Autostart | Задача в Планировщике заданий Windows с наивысшими правами, чтобы не было окна UAC при каждом запуске. |
| Tray + UI | Иконка в трее, большая кнопка, индикаторы по сервисам. |
| Diagnostics | Кнопка «Отправить отчёт»: собирает версию, текущую стратегию, результаты проверок (без ключа!) в текст, который можно скопировать и прислать. |
| Updater | Раз в день проверяет новые релизы zapret-discord-youtube и tg-ws-proxy, скачивает, проверяет, ставит и откатывает при проблемах (см. «Обновления»). |

Сторонние файлы, которые идут в комплекте: winws.exe и драйвер WinDivert из официальных релизов bol-van/zapret на GitHub, плюс ядро VPN. Брать только из официальных релизов, фиксировать версию и контрольные суммы.

## Разбор ключа vpn:// и выбор ядра VPN

Ключ `vpn://` — это собственный формат Amnezia: строка base64url, внутри которой 4 байта длины и сжатый zlib JSON-конфиг. В JSON есть поле `defaultContainer` и список `containers` с протоколами. Точную структуру нужно проверить на реальном ключе, запустив разбор локально.

Дальше ядро выбирается по протоколу:

| Протокол в ключе | Ядро | Как маршрутизировать |
|---|---|---|
| amnezia-xray (VLESS / Reality) | sing-box | По доменам, встроенными правилами sing-box. Самый простой вариант. |
| amnezia-awg (AmneziaWG) | amneziawg (официальный клиент или библиотека amneziawg-go) либо сборка sing-box с поддержкой AWG, если такая найдётся | По IP-адресам: в AllowedIPs только подсети Telegram и IP нейросетей, которые программа периодически определяет через DNS. |
| другое (OpenVPN, Shadowsocks) | sing-box, если поддерживает, иначе соответствующий клиент | По ситуации |

Требование: программа сама определяет протокол из ключа и показывает понятную ошибку, если он не поддерживается.

Списки для VPN:

- Telegram (только запасной режим, основной путь — tg-ws-proxy): домены telegram.org, t.me, telegram.me, tdesktop.com, telesco.pe плюс официальный список IP-подсетей Telegram (публикуется на core.telegram.org/resources/cidr.txt, хранить локальную копию и обновлять).
- Нейросети: chatgpt.com, openai.com, oaistatic.com, oaiusercontent.com, claude.ai, anthropic.com, gemini.google.com и связанные домены. Список вынести в отдельный редактируемый файл, чтобы дополнять без пересборки.

### Как сайты попадают в VPN (версия 0.6)

Маршрутизация только по списку адресов не работала: сайт (x.com) открывался, а его картинки, скрипты и данные с поддоменов на других адресах (abs.twimg.com, api.x.com) шли мимо VPN и висели. Поэтому:

- Туннель AmneziaWG поднимается с `Table = off` и `AllowedIPs = 0.0.0.0/0`: служба сама маршрутов не создаёт (и не включает блокировку остального трафика), а маршрутами в туннель управляет программа (TunnelRoutes, IP Helper API), на лету и без переподключения VPN.
- Пока VPN включён, DNS Windows указывает на программу (127.0.0.1 / ::1), вторым — прежний DNS. Вопросы о сайтах из списков и **любых их поддоменах** программа задаёт DNS Cloudflare через туннель (провайдер не подменит ответ) и добавляет полученные адреса в маршруты до того, как ответить браузеру. На IPv6-вопросы о них отвечает «адресов нет» — браузер идёт по IPv4 через туннель. Остальные вопросы уходят прежнему DNS как есть.
- Прежние настройки DNS сохраняются в файл до изменения; при выключении, выходе, выключении Windows и при следующем запуске после падения программа их возвращает.
- Если порт 53 занят или DNS переключить не удалось — запасной путь: адреса доменов узнаются заранее, как раньше.

## Zapret: стратегии, проверки и автопереключение

Zapret работает только для доменов из хостлиста (YouTube и Discord), поэтому остальной трафик он не трогает. Стратегии брать из готовых проверенных наборов (zapret-discord-youtube от Flowseal) и хранить в отдельном файле `strategies.json`, чтобы обновлять без пересборки.

Хостлист: youtube.com, googlevideo.com, ytimg.com, ggpht.com, youtu.be, discord.com, discord.gg, discordapp.com, discordapp.net, discord.media и связанные. Для голоса Discord нужны ещё UDP-стратегии, их тоже включить в набор.

Telegram тоже обходится без сервера: модуль запускает tg-ws-proxy от Flowseal. Он поднимает локальный MTProto-прокси на 127.0.0.1:1443 и пускает трафик Telegram через WebSocket-соединения к серверам Telegram. Программа один раз открывает ссылку `tg://proxy` на 127.0.0.1, бабушка жмёт «Подключить», и Telegram Desktop дальше сам ходит через этот прокси.

Проверка Telegram в HealthChecker: доступен ли локальный порт и отвечает ли web.telegram.org. Если не работает, Telegram уходит в VPN как запасной режим. Сам автор называет обход частичным, так что тяжёлые медиа могут грузиться хуже.

Как работает проверка и перебор:

1. При запуске берётся последняя рабочая стратегия (сохраняется в настройках).
2. HealthChecker каждые 2–3 минуты делает HTTPS-запрос к www.youtube.com, к одному из адресов googlevideo.com и к discord.com с таймаутом 5–8 секунд. Успех = прошёл TLS-рукопожатие и пришёл ответ.
3. Если проверка провалилась 2 раза подряд, ZapretManager останавливает winws и запускает следующую стратегию из списка.
4. После каждой смены стратегии сразу повторная проверка. Первая сработавшая сохраняется как рабочая.
5. Если перебраны все стратегии и ничего не помогло, YouTube и Discord временно уходят через VPN (запасной режим), а индикатор показывает «работает через запасной канал».
6. Раз в час программа пробует вернуться на zapret, чтобы не грузить сервер знакомого лишним видео.

Важно: нельзя проверять «просто есть ли интернет». Нужно проверять именно целевые сервисы, иначе программа не заметит, что YouTube отвалился.

## Обновления zapret и прокси Telegram

Стратегии zapret устаревают, когда провайдеры меняют DPI, а Flowseal выпускает новые версии часто. Ждать, пока внук заметит и обновит руками, — значит неделями сидеть без YouTube. Поэтому обновления автоматические, но осторожные.

Что обновляется:

| Компонент | Откуда | Что внутри |
|---|---|---|
| zapret | релизы Flowseal/zapret-discord-youtube | winws.exe, WinDivert, файлы-приманки, списки доменов, стратегии (.bat → strategies.json) |
| Прокси Telegram | релизы Flowseal/tg-ws-proxy | TgWsProxy_windows.exe |
| Сама программа | позже, отдельным этапом | — |

Как работает:

1. При запуске и раз в сутки Updater спрашивает GitHub API о последнем релизе обоих репозиториев. Только эти два репозитория, адреса зашиты в программу.
2. Новый релиз ставится не сразу, а когда ему исполнится 3 дня. Если релиз окажется битым или подменённым, за это время его успеют отозвать или заметят в обсуждениях.
3. Скачанный файл сверяется с SHA-256, который GitHub публикует для файлов релиза. Не совпало — файл удаляется, ставится старая версия.
4. Новая версия распаковывается в отдельную папку рядом со старой. Старая не удаляется, пока новая не доказала, что работает.
5. Для zapret стратегии из .bat переводятся в strategies.json тем же способом, что tools\import-strategies.ps1 (логику перенести в C#). Если формат .bat изменился и разобрать не удалось — обновление пропускается, в отчёт пишется причина.
6. Переключение: остановить компонент → указать на новую папку → запустить → проверка из HealthChecker. Для zapret запускается перебор стратегий, начиная с последней рабочей.
7. Откат: если после обновления открывается меньше сервисов, чем до него (или прокси Telegram не поднялся), программа возвращает старую версию и больше не пробует эту версию.
8. Хранится текущая и одна предыдущая версия, остальные удаляются.

В интерфейсе: в «Настройках» раздел «Обновления» — текущие версии, когда проверяли, есть ли новая; кнопка «Проверить сейчас»; переключатель «Обновлять автоматически» (по умолчанию включён). На главный экран обновления не выносятся; при неудачном обновлении бабушке ничего не показывается — оно просто откатывается, а причина попадает в отчёт.

Риск: автообновление означает, что программа сама ставит на компьютер новые exe из интернета. Если репозиторий Flowseal когда-нибудь взломают, плохая версия придёт автоматически. Защита — только официальные репозитории, сверка SHA-256, задержка в 3 дня и откат. Если такой риск неприемлем, переключатель «Обновлять автоматически» выключается, и обновления ставятся только по кнопке.

## Интерфейс для бабушки и дедушки

Главный экран: одна большая круглая кнопка «ВКЛЮЧИТЬ» / «ВЫКЛЮЧИТЬ» и под ней четыре строки с крупным шрифтом:

- YouTube — зелёный кружок «работает» или красный «не работает».
- Discord — то же самое.
- Telegram — то же самое.
- Нейросети — то же самое.

Правила интерфейса:

- Шрифт от 18 pt, высокий контраст, только русский язык.
- Никаких технических слов на главном экране: не «стратегия», не «туннель», а «Подбираю лучший способ…», «Всё работает».
- Кнопка «Вставить ключ» видна, только если ключа нет. Потом она уходит в меню «Настройки».
- Внизу вкладки «Главная», «Журнал», «Настройки». Отчёт копируется кнопкой «Скопировать отчёт» во вкладке «Журнал».

Экран «Настройки» (простой, тоже крупный шрифт):

- **Ключ VPN.** Поле «Вставить ключ» и кнопка «Проверить»: программа сразу пишет, подходит ли ключ («Ключ подходит», «Ключ повреждён — скопируй ещё раз», «Этот ключ не подходит, попроси другой»). Сам ключ на экране не показывается. Кнопка «Заменить ключ» для нового ключа от знакомого.
- **Состояние VPN.** «Подключено» / «Не подключено» / «Сервер не отвечает» и кнопка «Переподключить». Отдельно от главных индикаторов: по ним видно, отвалились ли нейросети, а здесь — почему.
- **Обновления.** Версии zapret и прокси Telegram, дата последней проверки, «Есть новая версия» / «Всё свежее», кнопка «Проверить сейчас», переключатель «Обновлять автоматически».
- Свернуть в трей при закрытии окна, а не выходить. Иконка в трее зелёная или красная.
- Всплывающее уведомление только если что-то сломалось и не починилось само за 5 минут: «Не всё работает. Открой «Журнал» и пришли отчёт».

## Телефоны

Телефоны — второй этап, своё приложение для них сначала не пишем. На Android одновременно может работать только одно VPN-приложение, поэтому ByeByeDPI и Amnezia вместе не запустятся.

На телефоне YouTube и Discord через VPN будут нагружать сервер знакомого.

Для Telegram на Android есть порт tg-ws-proxy (tg-proxy-android). Это локальный SOCKS5-прокси, а не VPN, поэтому он работает одновременно с Amnezia или ByeByeDPI. Перед установкой проверить, что это порт оригинального проекта, а не подделка.

| Телефон | Решение на первом этапе | Свой код |
|---|---|---|
| Android | Amnezia VPN с раздельным туннелированием: в VPN только Telegram, нейросети, а при необходимости YouTube и Discord. Остальное напрямую. Настроить один раз через удалённый доступ (RustDesk или AnyDesk). | Позже, если захочется: одно приложение на базе VpnService, объединяющее обход DPI (как в ByeDPI) и VPN. Это большой отдельный проект. |
| iPhone | Amnezia VPN или другой клиент с раздельным туннелированием. Обход DPI на iPhone невозможен. | Не планируем: нужен платный аккаунт разработчика Apple, а DPI всё равно не обойти. |

## Риски и важные нюансы

Главный практический риск: автор сам не в России, поэтому обход DPI у себя проверить не сможет. Тестировать zapret придётся на компьютере бабушки через удалённый доступ, поэтому режим диагностики и отчёт нужны с первой версии.

Отдельно про Telegram: брать tg-ws-proxy только из оригинального репозитория Flowseal. На GitHub много перепаковок с похожими названиями («обход всех сервисов в один клик» и т. п.), и часть из них может оказаться вредоносной.

| Риск | Что делать |
|---|---|
| Антивирус и Защитник Windows ругаются на WinDivert (ложное срабатывание) | Добавить папку программы в исключения при установке через удалёнку. Предупредить бабушку заранее. |
| Нужны права администратора | Манифест requireAdministrator + автозапуск через Планировщик с наивысшими правами. |
| Ключ принадлежит знакомому | Спросить разрешения на использование для ещё двух человек. Сделать простую замену ключа. |
| Один ключ AmneziaWG — одно устройство | Если один и тот же ключ включён одновременно в двух местах (у бабушки, у дедушки, в Amnezia VPN на телефоне), сервер общается только с последним подключившимся, и VPN «пропадает» то у одного, то у другого. Просить у знакомого отдельный ключ на каждое устройство. Программа при молчании сервера подсказывает это в сообщении. |
| Знакомый выключил сервер или сменил ключ | Telegram и нейросети отвалятся, YouTube и Discord останутся на zapret. Индикаторы это покажут. |
| Ключ уже засветился в чате | Попросить знакомого выдать новый ключ. В код ключ не вшивать, только вводить через интерфейс. |
| Условия использования нейросетей | Доступ к ChatGPT и Claude из неподдерживаемых стран через VPN нарушает их условия, аккаунты могут заблокировать. Как альтернатива — DeepSeek, который работает в России напрямую. |
| Белые списки мобильного интернета | Не помогут ни zapret, ни VPN. Это не про ПК на домашнем интернете. |
| Стратегии zapret устаревают | Автообновление из релизов Flowseal (см. «Обновления»), strategies.json обновляется без переустановки программы. |
| Драйвер WinDivert «завис» (`windivert: error opening filter … referenced by other objects`, FWP_E_IN_USE) | Программа больше не останавливает драйвер принудительно — после этого он и застревал. Если всё же случилось: zapret не перебирает все стратегии, а сразу просит перезагрузить компьютер и называет другие обходы блокировок, установленные службой (GoodbyeDPI, zapret). |
| Антивирус настораживается, что программа меняет DNS Windows | Это ложная тревога того же рода, что с WinDivert: добавить программу в исключения. DNS возвращается при выключении и после падения. |
| Автообновление принесёт плохую версию | Только официальные репозитории, сверка SHA-256, задержка 3 дня, автоматический откат, переключатель «Обновлять автоматически». |
| Сторонние бинарники | Брать winws, WinDivert и ядро VPN только из официальных релизов, проверять контрольные суммы. |

## Этапы разработки

Делать по одному этапу и проверять каждый, прежде чем идти дальше.

- **Этап 0. Подготовка.** Репозиторий для WPF-приложения на C# .NET 8, структура по модулям, манифест requireAdministrator, self-contained публикация в один exe. Только каркас и пустое окно.
- **Этап 1. Разбор ключа.** KeyParser: base64url, 4 байта длины, zlib, JSON. Протокол из `defaultContainer` и `containers`. Юнит-тесты на синтетическом ключе (реальный ключ в репозиторий не класть). Хранение через DPAPI. Консольная команда, выводящая только название протокола, без секретов.
- **Этап 2. Zapret.** ZapretManager (winws.exe + WinDivert, strategies.json, хостлист), TelegramProxy (tg-ws-proxy + `tg://proxy`), корректная остановка процессов, HealthChecker для YouTube и Discord и логика перебора стратегий.
- **Этап 3. VPN и раздельная маршрутизация.** VpnManager и Router под протокол из этапа 1. Через VPN нейросети из `ai-domains.txt` и заблокированные сайты из `blocked-domains.txt`/`blocked-cidr.txt` (Telegram, YouTube и Discord — только запасной режим). Проверки Telegram и нейросетей в HealthChecker. Запасной режим.
- **Этап 4. Интерфейс.** По разделу «Интерфейс для бабушки и дедушки», в современном тёмном стиле: большая круглая кнопка питания с подсветкой, четыре карточки сервисов с кнопками «Подключить» (Telegram) и «Вставить ключ», «Настройки» (ключ VPN, состояние VPN, версии), вкладки Главная / Журнал / Настройки в одном окне (журнал и «Скопировать отчёт» — во вкладке «Журнал»), трей с цветным значком, уведомление при поломке дольше 5 минут. Индикатор Telegram зелёный, только когда Telegram действительно подключён к прокси.
- **Этап 5. Обновления.** Updater по разделу «Обновления»: проверка релизов, задержка 3 дня, SHA-256, установка рядом со старой версией, проверка и откат, перенос import-strategies в C#. Кнопка «Проверить сейчас» и переключатель в «Настройках».
- **Этап 6. Автозапуск, диагностика, установщик.** Планировщик заданий с наивысшими правами, «Скопировать отчёт» (без ключа и личных данных, с версиями компонентов и историей обновлений), логи только ошибок с ротацией до 1 МБ, установщик Inno Setup.
- **Этап 7. Тест у бабушки.** Установка через удалённый доступ, исключение в антивирусе, вставить ключ, проверить четыре сервиса и российские сайты (банк, Госуслуги). Прогнать день, посмотреть отчёт, поправить стратегии.

## Открытые вопросы

- ~~Какой протокол внутри ключа: amnezia-xray или amnezia-awg?~~ Ответ: **amnezia-awg (AmneziaWG)**, проверено ПроверитьКлюч.exe. Этап 3 — ядро amneziawg, маршрутизация по IP.
- Разрешает ли знакомый пользоваться ключом ещё двум людям? Важно: ключ AmneziaWG работает только на одном устройстве одновременно, поэтому нужен отдельный ключ на каждый компьютер и телефон.
- Выдаст ли знакомый новый ключ взамен засвеченного в чате?
- Какие телефоны у бабушки и дедушки: Android или iPhone?
- Какая версия Windows на их компьютере (10 или 11) и какой антивирус стоит?
- Какой программой удалённого доступа будешь подключаться к ним?
