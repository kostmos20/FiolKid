<h1 align="center">FiolKid</h1>

<p align="center">
  Одна программа для Windows, чтобы в России снова работали YouTube, Discord, Telegram, нейросети
  и заблокированные сайты — без настроек и технических слов.
</p>

---

## Зачем она

Обычно, чтобы всё работало, приходится держать сразу несколько программ: zapret для YouTube,
отдельный прокси для Telegram, VPN для ChatGPT — и помнить, что включать и когда. Через VPN при этом
часто гонят вообще весь интернет, и тогда начинают тормозить российские сайты и банки.

FiolKid делает всё это сам, по одной кнопке. Каждый сервис идёт самым подходящим путём:

| Что | Как открывается | Нужен ли сервер |
|---|---|---|
| YouTube, Discord | обход блокировок **zapret** прямо на компьютере | нет |
| Telegram | локальный прокси **tg-ws-proxy** | нет |
| ChatGPT, Claude, Gemini и др. | через **VPN** | да: ключ Amnezia или подписка |
| Instagram, X и другие заблокированные сайты | через **VPN** | да |
| Российские сайты, банки, Госуслуги | **напрямую**, как без программы | — |

Программа сделана для близких: бабушек, родителей, друзей, которым не хочется разбираться
в настройках. Поэтому в ней большая кнопка, понятные надписи и кнопка «Скопировать отчёт»,
если что-то пошло не так.

## Как пользоваться

1. Скачать архив `FiolKid.zip` со страницы [Releases](../../releases) и распаковать его **целиком**
   в любую папку, например на рабочий стол.
2. Запустить `FiolKid.exe`. Windows спросит разрешение — нужно согласиться: без прав администратора
   обход блокировок не работает.
3. Нажать большую кнопку. Программа сама подберёт способ обхода для YouTube и Discord.
4. Для Telegram нажать «Подключить» — Telegram спросит «Подключить прокси?», ответить «Подключить».
5. Для нейросетей и заблокированных сайтов: **Настройки → Вставить ключ** (ключ Amnezia `vpn://…`)
   или **Вставить ссылку** (ссылка-подписка `https://…`). Ключ или ссылку нужно сначала скопировать.

Если закрыть окно крестиком, программа продолжит работать — её значок останется возле часов.
Выключить совсем — правой кнопкой по значку → «Выйти совсем».

**Требования:** Windows 10 или 11, 64-бит. Устанавливать ничего не нужно, .NET уже внутри.

## Что умеет

- **Сама подбирает способ обхода (альт) для YouTube и Discord.** По умолчанию замеряет все способы
  по скорости загрузки и берёт самый быстрый. Можно выбрать «первый рабочий» или конкретный альт вручную.
- **Следит, чтобы всё работало.** Каждые 2,5 минуты проверяет сервисы. Перестал работать альт —
  подберёт другой; не помог ни один — пустит YouTube и Discord через VPN, а через час попробует снова.
- **Два вида VPN.** Ключ Amnezia (AmneziaWG) или ссылка-подписка со списком серверов (VLESS, Hysteria2,
  Trojan, Shadowsocks). Если вставлено и то и другое — берёт то, что работает быстрее.
- **Выбирает лучший сервер подписки.** Перед подключением меряет у каждого сервера задержку, скорость
  и страну выхода. Подключается к трём лучшим, серверы с выходом из России для нейросетей не берёт.
  Можно выбрать сервер вручную.
- **Через VPN — только то, что нужно.** Свой DNS отправляет в туннель сайты из списков и все их
  поддомены; остальное идёт напрямую. Список заблокированных сайтов обновляется сам раз в сутки.
- **Понятный отчёт.** Вкладка «Журнал» → «Скопировать отчёт»: что работает, что нет и почему,
  что на компьютере может мешать (другие VPN, включённый системный прокси, переписанный файл hosts).
  Журнал хранится в файлах за 7 дней.
- **Запуск вместе с Windows** — сразу в трей, без окна.
- **Обновляется сама.** Раз в 6 часов смотрит, не вышла ли новая версия, и предлагает «Обновить».
  Ключ, подписка и настройки при обновлении сохраняются.

## Обновления

Новые версии выкладываются в раздел [Releases](../../releases) этого репозитория. Программа:

1. Спрашивает GitHub, какая версия последняя, и скачивает её описание: версию, размер и SHA-256 архива.
2. **Проверяет подпись описания.** Выпуски подписываются ключом автора (ECDSA P-256), а открытая часть
   ключа встроена в программу. Без закрытого ключа подделать выпуск нельзя — даже имея доступ к репозиторию.
3. Скачивает архив и сверяет его размер и SHA-256 с подписанным описанием.
4. Выключает zapret, VPN и прокси, возвращает DNS и закрывается. Новая версия заменяет только
   изменившиеся файлы и запускается сама. Свои списки сайтов (`*-user.txt`) не перезаписываются,
   заменённые файлы сохраняются в резервную копию, а если что-то не скопировалось — всё возвращается назад.

## Как это устроено

```
                       ┌──────────────── FiolKid ────────────────┐
  YouTube, Discord ──► │ zapret (winws + драйвер WinDivert)       │ ──► напрямую, DPI не узнаёт
  Telegram ─────────►  │ tg-ws-proxy (127.0.0.1:1443)             │ ──► серверы Telegram
  ChatGPT, Instagram ► │ свой DNS → маршруты → туннель «FiolKid»  │ ──► VPN-сервер ──► сайт
  остальное ────────►  │                                          │ ──► напрямую
                       └──────────────────────────────────────────┘
```

- **zapret** (winws от Flowseal) работает только для доменов YouTube и Discord и меняет пакеты так,
  что оборудование провайдера (DPI) не узнаёт, куда идёт соединение.
- **tg-ws-proxy** — локальный MTProto-прокси: Telegram подключается к нему, а он ходит к серверам
  Telegram через WebSocket.
- **VPN** поднимается без своих маршрутов: AmneziaWG (`Table = off`) или sing-box (без auto_route).
  Что пустить в туннель, решает программа. Пока VPN включён, DNS Windows указывает на программу
  (127.0.0.1): вопросы о сайтах из списков она задаёт DNS Cloudflare через туннель и до ответа браузеру
  добавляет полученные адреса в маршруты VPN. Остальные вопросы уходят прежнему DNS.
  Прежние настройки DNS программа возвращает при выключении, а если она упала — это делает
  отдельный сторожевой процесс.
- **Watchdog** проверяет сервисы настоящими запросами (YouTube, видеосервер Google, Discord,
  сквозная проверка Telegram через прокси, страна, которую видит ChatGPT) и переключает способы.

Подробно — в [PLAN.md](PLAN.md).

## Безопасность и приватность

- **Ключи и подписки никуда не отправляются.** Они нужны только для подключения к вашему VPN-серверу.
- **Хранятся зашифрованными** (Windows DPAPI) в `%LOCALAPPDATA%`, прочитать их может только ваша учётная
  запись на этом компьютере. Конфиги VPN с ключами лежат в папке, доступной только системе
  и администраторам, и удаляются после остановки.
- **На экране, в журнале и в отчёте ключей, ссылок-подписок и паролей серверов нет.** В отчёте есть
  сетевые сведения (адреса сайтов, страна и внешний IP, который видит ChatGPT) — учитывайте это,
  если пересылаете его посторонним.
- **В этом репозитории нет настоящих ключей.** В тестах только выдуманные данные (адреса из диапазона
  для примеров `203.0.113.0/24`, пароли вида `FAKE-PSK`).
- **Внешние программы скачиваются только с официальных релизов** их авторов и сверяются по SHA-256
  (`tools/fetch-deps.ps1`).
- Программа не отправляет никакой статистики. В интернет она ходит только к проверяемым сервисам,
  к сайту подписки (если она вставлена), за обновлением списка блокировок и на GitHub за новой версией.

Один ключ Amnezia — одно устройство: если тот же ключ включён ещё где-то, VPN будет работать с перебоями.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и PowerShell.

```powershell
# 1. Скачать zapret, tg-ws-proxy, AmneziaWG и sing-box с официальных релизов (со сверкой SHA-256)
powershell -ExecutionPolicy Bypass -File tools\fetch-deps.ps1

# 2. Тесты
dotnet test tests\ZapretPro.Core.Tests

# 3. Собрать dist\ и FiolKid.zip
powershell -ExecutionPolicy Bypass -File build.ps1
```

Выпуск новой версии (только для автора — нужен ключ подписи и вход в GitHub CLI):

```powershell
# один раз на компьютере автора: создать ключ подписи (хранится зашифрованным вне репозитория)
dotnet run --project src\ZapretPro.ReleaseTool -- keygen

# поднять <Version> в src\ZapretPro.App\ZapretPro.App.csproj, сохранить в git, затем:
powershell -ExecutionPolicy Bypass -File tools\publish-release.ps1 -Notes "Что нового"
```

Структура:

| Папка | Что там |
|---|---|
| `src/ZapretPro.App` | окно, трей, вкладки (WPF) |
| `src/ZapretPro.Core` | вся логика: zapret, Telegram, VPN, свой DNS, проверки |
| `src/ZapretPro.KeyTool` | `ПроверитьКлюч.exe` — показывает, какой протокол в ключе |
| `src/ZapretPro.ReleaseTool` | ключ подписи выпусков и подпись (только для автора) |
| `tests/ZapretPro.Core.Tests` | тесты (xUnit) |
| `data` | способы обхода zapret и списки сайтов для VPN |
| `tools` | скачивание компонентов, обновление списков, рисование значка |
